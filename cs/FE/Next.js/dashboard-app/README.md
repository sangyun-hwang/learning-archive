# Next.js Dashboard App 실습

Next.js 공식 Dashboard App 과정을 따라가며 App Router 기반 웹 애플리케이션의 구조와 데이터 흐름을 확인한 기록이다. 코드 작성 과정은 별도 실습 저장소에서 관리하고, 이곳에는 각 Chapter에서 이해한 개념과 확인한 동작만 정리한다.

- [Practice Repository](https://github.com/sangyun-hwang/nextjs-dashboard-practice)
- [Official Course](https://nextjs.org/learn/dashboard-app)
