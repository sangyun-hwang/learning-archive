# OpenCode

OpenCode는 터미널, 데스크톱 앱, IDE에서 사용할 수 있는 오픈소스 AI coding agent이다.

단순히 질문에 답하는 챗봇이라기보다, 코드베이스를 읽고 계획을 세우며 필요한 경우 파일을 수정하고 변경 사항을 되돌리는 작업까지 도와주는 개발 보조 에이전트에 가깝다.

## 챗봇과 Coding Agent의 차이

일반적인 챗봇은 주로 텍스트 답변을 생성한다.

반면 coding agent는 프로젝트 안에서 다음과 같은 작업을 수행할 수 있다.

- 파일과 디렉터리 구조 읽기
- 기존 코드 흐름 파악
- 수정 계획 작성
- 코드 변경 적용
- 변경 사항 diff 확인
- 필요하면 변경 되돌리기

즉 OpenCode는 코드에 대해 설명만 하는 도구가 아니라, 개발 작업의 일부를 직접 수행할 수 있는 에이전트로 볼 수 있다.

## Plan Mode와 Build Mode

OpenCode는 작업 모드를 나누어 사용할 수 있다.

### Plan Mode

Plan Mode는 코드를 바로 수정하지 않고, 먼저 문제를 분석하고 작업 계획을 세우는 단계이다.

이 모드는 다음과 같은 상황에 적합하다.

- 변경 범위가 큰 작업
- 설계 판단이 필요한 작업
- 먼저 방향을 검토하고 싶은 작업
- 에이전트가 바로 파일을 수정하지 않게 하고 싶은 경우

### Build Mode

Build Mode는 실제로 파일을 수정하고 구현을 진행하는 단계이다.

Plan Mode에서 세운 계획이 적절하다고 판단되면 Build Mode로 넘어가 코드를 변경할 수 있다.

두 모드를 나누면 에이전트가 바로 코드를 수정하는 위험을 줄이고, 사람이 먼저 방향을 검토한 뒤 실행할 수 있다.

## AGENTS.md

`README.md`가 사람을 위한 프로젝트 설명 문서라면, `AGENTS.md`는 AI 에이전트를 위한 프로젝트 가이드 문서에 가깝다.

예를 들어 다음과 같은 내용을 담을 수 있다.

- 프로젝트 구조
- 빌드와 테스트 명령어
- 코드 스타일
- 작업 시 주의할 점
- 변경하면 안 되는 영역
- 리뷰나 커밋 규칙

에이전트는 `AGENTS.md`를 참고해서 프로젝트의 맥락과 규칙을 이해하고 작업한다.

## 정리

OpenCode는 단순히 코딩 질문에 답하는 도구가 아니라, 프로젝트를 읽고 계획하고 수정하는 개발 작업 흐름에 들어오는 AI coding agent이다.

다만 에이전트가 할 수 있는 일이 많을수록 잘못된 변경의 영향도 커질 수 있으므로, Plan Mode로 먼저 방향을 확인하고 Build Mode에서 구현하는 식으로 안전하게 사용하는 것이 중요하다.
