# Aside Browser: 브라우저 에이전트의 작업 실행

## 개념

Aside는 로그인된 웹사이트와 계정을 활용해 여러 단계의 작업을 수행하는 AI 브라우저다. 페이지를 읽고 답하는 기능에 더해 탐색, 입력과 파일 작업을 연결하는 제품으로 이해한다. [공식 도움말](https://docs.aside.com/)

예를 들어 '지난달 청구서를 찾아 다운로드하고 금액을 표로 정리해 달라'는 목표를 받으면 페이지 확인, 이동, 다운로드와 결과 정리를 이어가는 흐름을 구성할 수 있다. 이 예시는 활용 시나리오이며 직접 실행해 검증한 결과는 아니다.

## 판단과 실행의 분리

| 구성 | 역할 |
| --- | --- |
| LLM | 요청과 페이지 정보를 바탕으로 다음 행동 판단 |
| 브라우저 제어 도구 | 페이지 읽기, 클릭과 입력 등 실제 동작 수행 |
| 실행 결과 | 행동이 성공했는지 확인할 근거 제공 |
| 권한 시스템 | 파일과 도구 접근 등 허용 범위 관리 |

```text
사용자 목표
-> 현재 페이지 확인
-> 다음 행동 판단
-> 도구로 실행
-> 결과 확인
-> 다음 행동 또는 완료
```

Tool Use와 Agent Loop가 브라우저 작업에 적용된 사례로 볼 수 있다. LLM이 클릭을 결정하더라도 실제 실행은 연결된 도구가 수행한다.

공식 문서는 웹 탐색, 파일 사용, 기록 검색, 허용된 자동 로그인과 승인 요청을 여러 단계 작업에 연결하는 기능을 설명한다. 실제 수행 가능 여부는 사이트 구조, 로그인 상태와 접근 권한 등에 따라 달라진다. [작업 실행 문서](https://docs.aside.com/help/tasks)

## 자연어 위임과 코드 자동화

| 방식 | 다음 행동을 정하는 방법 | 고려할 점 |
| --- | --- | --- |
| 코드 기반 자동화 | 개발자가 작성한 절차, 조건과 선택자 | 반복 실행과 검증이 쉬우나 변경에 맞춘 유지보수 필요 |
| 자연어 목표 위임 | 에이전트가 관찰 결과를 바탕으로 다음 행동 선택 | 상황에 대응할 여지가 있지만 잘못된 판단과 결과 검증 필요 |

코드 자동화도 조건 분기, 재시도와 안정적인 선택자로 변경에 대응할 수 있다. 항상 정확하거나 변경에 전혀 대응할 수 없는 매크로로 단정하지 않는다. 자연어 에이전트 역시 사이트 변경을 반드시 해결하는 것은 아니다.

개발자가 정해 둔 절차와 모델이 선택할 범위를 조합하고, 실행 후 목표 달성 여부를 확인하는 것이 중요하다.

## CLI, MCP와 REPL

Aside는 CLI, MCP와 브라우저 자동화 REPL을 제공한다. CLI로 에이전트 작업을 시작하거나 MCP로 다른 에이전트에 연결하고, REPL로 코드 기반 브라우저 제어를 수행할 수 있다. [개발자 문서](https://docs.aside.com/help/developers)

MCP는 연결 방식이며 모든 브라우저 작업이 LLM 추론을 요구한다는 뜻은 아니다. 정해진 코드로 도구를 호출하는 것과 목표를 받아 행동을 선택하는 에이전트 실행을 구분한다.

## 로그인된 계정의 권한

비밀번호 값을 모델에 숨기는 것과 로그인된 계정으로 무엇을 할 수 있는지는 별개다. 계정에 로그인된 상태라면 허용된 도구를 통해 메일 발송이나 정보 변경 같은 영향을 줄 수 있다.

예를 들어 '메일 요약' 요청이 '메일 발송'까지 승인한 것은 아니다. 사용자 의도와 작업 범위를 벗어나지 않도록 권한을 제한하고 필요한 확인 절차를 둔다. 웹페이지의 외부 콘텐츠에 포함된 지시를 따르는 Prompt Injection도 고려한다.

공식 문서는 파일 접근 범위, 도구의 Allow / Ask / Deny와 명령 샌드박스 설정을 설명한다. 비밀번호 관리자는 저장된 비밀번호 값을 AI 에이전트에 숨긴 채 자동 입력하도록 설계됐다고 설명한다. 이는 제품 문서의 설명이며 독립적인 보안 검증 결과를 의미하지 않는다. [권한 문서](https://docs.aside.com/help/security)

## 간단한 실습 방향

테스트 페이지에서 상품 세 개의 이름과 가격을 비교하는 등 결과를 직접 확인할 수 있는 작업으로 시작한다. 자연어로 목표를 맡겼을 때 실제 사용한 페이지, 추출한 값과 완료 결과가 맞는지 확인한다. 이후 같은 작업을 코드 기반 제어로 수행하면 두 방식의 차이를 비교할 수 있다.

## 면접용 설명

Aside Browser는 로그인된 웹 환경에서 탐색과 입력 등 여러 단계를 수행하는 브라우저 에이전트입니다. LLM이 다음 행동을 판단하고 브라우저 도구가 실행한 뒤 결과를 확인하는 흐름입니다. 코드 자동화와 비교하면 목표에 따라 행동을 선택할 수 있지만 정확성이 보장되는 것은 아니며, 계정 사용 권한과 결과 검증이 중요합니다.
