# FDE (Forward Deployed Engineer)

## 개념

FDE는 고객의 실제 업무와 환경을 이해하고, 자사 기술을 활용한 해결책을 직접 구현해 현장에 적용하는 엔지니어다. 고객과의 문제 정의부터 개발, 시스템 통합, 배포와 적용 결과 확인까지 이어지는 역할로 이해할 수 있다.

고객사 방문이나 상주가 포함될 수 있지만 근무 장소만으로 정의하지 않는다. 회사별로 개발 범위와 운영 책임은 다르다. Palantir의 FDE 공고는 고객과의 첫 대화부터 고객 환경에 맞는 애플리케이션과 운영용 솔루션 구현까지 다룬다. [Palantir 직무 설명](https://jobs.lever.co/palantir/5168e8fd-fec1-4fea-b7a1-81bdaea65850)

## 고객의 요구를 그대로 구현하는 것으로 부족한 이유

고객마다 기존 시스템, 데이터 품질, 보안 정책과 업무 절차가 다르다. 요구사항이 불명확하거나 필요한 정보가 빠져 있을 수도 있다. 따라서 요청한 기능이 실제 문제를 해결하는지 먼저 확인해야 한다.

예를 들어 '배송 현황 대시보드가 필요하다'는 요청의 원인은 화면 부족일 수도 있지만, 배차 정보가 늦게 입력되거나 담당자에게 지연 알림이 전달되지 않는 문제일 수도 있다. 원인에 따라 구현할 기능과 연결할 시스템이 달라진다.

## 업무 흐름 예시

다음은 물류 회사의 배송 지연 문제를 가정한 학습용 예시다.

1. 현장 담당자와 주문·배차·배송 절차를 파악한다.
2. 지연 원인과 개선 목표를 정한다.
3. 주문 시스템, 차량 정보 등 필요한 데이터를 연결한다.
4. 대시보드와 담당자 알림 기능을 구현한다.
5. 실제 환경에 배포하고 사용자 피드백을 반영한다.
6. 지연 건수나 대응 시간이 개선됐는지 확인한다.

화면이 정상적으로 실행되는 것뿐 아니라 현장에서 사용되고 업무 결과가 개선되는지를 확인한다.

## 다른 역할과 비교

| 역할 | 주로 집중하는 관점 |
| --- | --- |
| 제품 개발자 | 여러 고객이 공통으로 사용할 제품 기능 |
| FDE | 특정 고객 환경에서 해결해야 하는 문제와 구현 |
| 솔루션·세일즈 엔지니어 | 기술의 적합성 설명과 검증 |
| 컨설턴트 | 전략과 업무 개선 방향 |

역할은 서로 겹칠 수 있다. 컨설턴트와 솔루션 엔지니어도 개발할 수 있으며, 제품 개발자도 고객 문제를 조사한다. 직함만으로 구분하기보다 실제 공고의 구현·배포 책임을 확인한다.

고객별 해결책에서 반복되는 요구를 발견하면 공통 제품 기능이나 재사용 가능한 도입 방식으로 되돌려 줄 수도 있다. Anthropic의 FDE 공고도 운영용 AI 애플리케이션 구현과 반복 가능한 배포 패턴을 제품·개발 팀에 전달하는 역할을 포함한다. [Anthropic 직무 설명](https://job-boards.greenhouse.io/anthropic/jobs/5391021008)

## AI 도입에서의 역할

AI 고객지원 데모가 동작해도 실제 도입에는 사내 데이터 연결, 답변 품질 평가, 권한 처리와 상담원에게 넘기는 흐름이 필요하다. 비용, 응답 시간과 장애 상황도 고객 업무에 맞춰 확인해야 한다.

```text
고객 업무 파악
-> AI를 적용할 작업과 성공 기준 정의
-> 기존 데이터와 API 연결
-> UI와 업무 흐름 구현
-> 품질 평가와 권한 처리
-> 배포, 피드백과 성과 확인
```

FDE는 직무이고 AX는 AI로 업무와 서비스를 개선하는 방향이다. FDE가 AI 도입을 담당할 수 있지만 모든 FDE가 AI 모델을 연구하거나 직접 학습시키는 것은 아니다.

## 프론트엔드 경험과 연결하기

프론트엔드 경험은 고객의 작업을 화면으로 구현하고 기존 시스템과 연결하는 데 활용할 수 있다.

- 업무 흐름에 맞는 대시보드와 승인 화면 구현
- 기존 API, 로그인과 사용자 권한 연결
- 고객의 브라우저·네트워크 환경에 맞춘 성능과 오류 처리
- AI 처리 상태, 결과와 사람의 검토 흐름 표시
- 실제 사용자 피드백을 통한 사용성 개선

고객 환경에 맞게 동작을 조정하는 것과 함께, 어떤 문제를 해결할 화면인지 정의하는 일이 중요하다. 필요한 역량은 프론트엔드뿐 아니라 API·데이터·배포 이해와 고객 커뮤니케이션까지 확장되며 회사에 따라 범위가 달라진다.

## 면접용 설명

FDE는 고객 업무와 환경에 깊이 들어가 자사 기술로 문제를 해결하는 엔지니어입니다. 불명확한 요구를 구체적인 문제로 바꾸고, 기존 시스템과 통합해 실제로 사용하는 해결책을 구현합니다. 제품 개발자가 공통 기능에 더 집중한다면 FDE는 특정 고객의 문제와 적용 결과에 더 집중하며, 프론트엔드 경험도 업무 화면과 데이터·권한 흐름을 구현하는 데 활용할 수 있습니다.
