# ego(lite): 에이전트와 함께 사용하는 브라우저

## 개념

ego(lite)는 Chromium 기반 브라우저다. 사용자가 직접 탐색하는 동시에 호환되는 AI 에이전트가 브라우저 작업을 수행하도록 구성한다. 에이전트는 ego-browser 연결 도구를 통해 페이지를 읽고 클릭·입력 등을 실행한다. [공식 소개](https://www.egolite.ai/document/en/docs/windows/product-introduce)

## 판단과 실행

| 구성 | 역할 |
| --- | --- |
| 연결된 AI 에이전트 | 사용자 목표와 페이지 정보를 바탕으로 다음 행동 판단 |
| 브라우저 제어 도구 | 페이지 이동, 읽기, 클릭과 입력 등 실제 조작 |
| 사용자 | 결과 확인과 필요한 승인·수동 입력 |

```text
상품 세 개를 비교해 달라는 요청
-> 작업용 Space에서 페이지 열기
-> Snapshot으로 내용과 조작 대상 확인
-> 에이전트가 다음 행동 판단
-> 도구로 이동·클릭
-> 결과 확인 후 답변
```

위는 활용 흐름을 설명한 예시다. 직접 실행해 성공을 검증한 결과는 아니다.

## Space와 Snapshot

Space는 작업용 탭을 묶는 브라우저 안의 공간이다. 기존 로그인 상태를 활용할 수 있으며 작업을 나누어 관리하는 데 사용한다. **작업 페이지의 분리가 독립된 계정이나 보안 권한의 격리를 의미하지는 않는다.**

Snapshot은 페이지 내용과 조작 대상을 구조화된 텍스트로 제공한다. 입력창이나 버튼에 참조를 붙여 이후 조작에 사용한다. 페이지가 변경되면 기존 참조가 유효하지 않을 수 있으므로 새 Snapshot을 확인한다. [공식 기능 설명](https://www.egolite.ai/document/en/docs/windows/product-introduce)

브라우저 도구를 사용해 실행하더라도 에이전트가 항상 올바른 버튼을 선택한다는 보장은 없다. 실행 후 화면과 결과를 확인한다.

## Aside와 비교

| 관점 | Aside | ego(lite) |
| --- | --- | --- |
| 대표적인 사용 흐름 | 브라우저 에이전트에 목표를 맡겨 여러 단계 실행 | 사용 중인 에이전트가 ego-browser로 브라우저 제어 |
| 외부 연결 | CLI·MCP·REPL | Skill과 브라우저 제어 도구 |
| 공통점 | 로그인된 웹 환경의 탐색·입력 등 작업 | 로그인된 웹 환경의 탐색·입력 등 작업 |

Aside도 외부 제어 기능이 있으므로 'Aside는 내장 AI만, ego는 외부 AI만'으로 나누지 않는다. 대체 가능성은 필요한 사이트, 에이전트 연동과 권한 관리, 실제 작업 결과를 비교해 판단한다. [Aside 개발자 문서](https://docs.aside.com/help/developers)

ego(lite)의 공식 저장소는 ego-browser 연결 도구와 사용 흐름을 설명한다. 저장소의 라이선스를 브라우저 앱 전체의 소스 공개 범위와 동일하게 해석하지 않는다. [공식 저장소](https://github.com/citrolabs/ego-lite)

## 로컬 실행과 정보 전달

로컬에서 브라우저가 실행된다는 사실이 모델 추론과 데이터 처리까지 모두 로컬이라는 뜻은 아니다. 에이전트가 읽은 페이지 내용은 선택한 모델 제공자에게 전달될 수 있다. 모델과 도구 구성에 따라 실제 데이터 흐름을 확인한다. [공식 개인정보 설명](https://www.egolite.ai/document/en/docs/windows/product-introduce#privacy)

로그인 상태를 활용하면 비밀번호를 다시 입력하지 않아도 계정의 기능에 접근할 수 있다. Space가 다르다는 이유만으로 이러한 권한이 제한됐다고 가정하지 않는다. 사용자가 요청한 조회 작업과 게시·삭제 같은 변경 작업의 범위를 구분한다.

## 실습 방향

테스트 페이지에서 상품 이름과 가격을 읽고 비교하는 작업으로 시작할 수 있다. 에이전트가 사용한 페이지와 추출한 값, 최종 답변을 직접 대조한다. 여러 작업을 나눌 때는 Space의 탭 구분과 실제 로그인 상태를 별도로 확인한다.

## 말로 설명하기

ego(lite)는 사용 중인 AI 에이전트가 로그인된 웹 환경에서 작업하도록 연결하는 Chromium 브라우저입니다. 에이전트가 다음 행동을 판단하고 브라우저 도구가 실제 페이지를 조작합니다. 작업은 Space로 나누고 페이지는 Snapshot으로 읽지만, Space가 계정 권한까지 격리하는 것은 아닙니다. 로컬 브라우저여도 읽은 내용이 외부 모델 제공자에게 전달될 수 있어 데이터 흐름을 확인해야 합니다.
