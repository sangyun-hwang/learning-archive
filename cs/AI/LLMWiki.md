# LLM Wiki와 Second Brain

## 개념

LLM Wiki는 AI가 자료를 읽고 주제별 문서를 작성·연결·갱신하는 지식 관리 패턴이다. 여기서는 Karpathy의 제안을 기준으로 이해한다. 특정 모델이나 제품 이름은 아니다. [LLM Wiki 원문](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)

Second Brain은 기억과 생각을 외부 기록으로 관리하고 다시 활용하는 관점이다. LLM Wiki에서는 AI가 문서 유지보수를 돕는다. 사람은 자료를 고르고, 질문하고, 결과를 검토한다.

## Obsidian과의 관계

Obsidian처럼 Markdown 문서를 링크로 연결해 보는 도구와 잘 맞는다. 다만 Obsidian은 문서를 읽고 편집하는 도구이고 LLM Wiki는 문서를 관리하는 운영 방식이다. GitHub의 Markdown 문서로도 구성할 수 있다.

## 요약 모음에서 연결된 지식으로

자료별 요약을 추가하는 데 더해 새 내용이 기존 설명에 미치는 영향을 반영한다. 관련 페이지를 연결하고, 중복을 통합하며 모순이나 오래된 주장을 확인한다.

```text
새 자료
-> 기존 관련 문서 확인
-> 설명 보충과 비교
-> 연결·목차 갱신
-> 변경 검토
-> 이후 질문에 재사용
```

## 원본, Wiki, 운영 규칙

| 구성 | 역할 |
| --- | --- |
| 원본 자료 | 공식 문서·논문·사용자 메모 등 근거 |
| 정리된 Wiki | 자료를 종합한 개념·비교·연결 문서 |
| 운영 규칙 | 문서 구조, 출처 표시와 갱신 절차 |

원본과 정리본을 구분하면 요약이 잘못됐을 때 근거로 돌아가 확인할 수 있다. 출처 자체의 정확성과 최신성도 검토한다. 운영 규칙은 AGENTS.md 같은 문서로 전달할 수 있다.

원문은 자료 반영(ingest), 질문과 탐색(query), 연결·모순·누락 점검(lint)을 반복하는 방식을 제안한다. 답변에서 얻은 유용한 비교도 Wiki에 남겨 재사용할 수 있다. [원문 구조와 운영 방식](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f)

## RAG와 비교

| 관점 | 일반적인 RAG | LLM Wiki 패턴 |
| --- | --- | --- |
| 중심 | 질문에 관련된 자료를 검색해 답변 | 자료를 미리 종합하고 지속적으로 갱신 |
| 관리 대상 | 원본과 검색 인덱스 등 | 주제 문서와 연결 관계 등 |
| 결합 | Wiki 문서도 검색 대상으로 활용 가능 | 규모에 맞춰 검색 기능 추가 가능 |

두 방식은 함께 사용할 수 있다. RAG도 요약·저장을 결합할 수 있으므로 'RAG에는 축적이 없고 Wiki만 기억한다'고 일반화하지 않는다.

## 문서 활용과 모델 학습의 차이

문서를 저장한 뒤 다음 질문에서 읽어도 모델의 가중치가 자동으로 바뀌지는 않는다. 이 방식에서 쌓이는 것은 외부 지식 문서다.

```text
문서 저장 -> 필요한 문서 읽기 -> 답변에 활용
= 외부 지식을 문맥으로 제공

학습 절차로 모델 가중치 변경
= 모델 자체의 학습
```

모델이 문서를 읽고 새롭게 정리했다는 사실도 가중치 학습을 의미하지 않는다. 잘못된 정리가 반복 사용되면 오류가 이어질 수 있으므로 출처와 변경 이력을 남기고 검토한다.

## learning-archive에 연결해 보기

이 아카이브의 문서는 대화를 거쳐 요약·보충한 정리본이다. 파일이 모여 있다는 이유로 모두 원본 자료라고 취급하지 않는다. 공식 출처와 사용자 설명, 종합한 정리를 구분한다.

예를 들어 React Activity 자료를 반영할 때 Activity 문서와 Effect·상태 보존·브라우저 생명주기의 관계도 검토할 수 있다. Activity의 UI 보존과 브라우저의 페이지 폐기를 혼동한 설명이 있다면 함께 수정한다.

별도 Wiki를 복제하기보다 기존 문서의 연결과 갱신 규칙을 개선하는 방식도 가능하다. 이 문서는 그 적용 방향을 설명하며 저장소 전체를 재구성하거나 자동 유지보수 시스템을 구축한 결과는 아니다.

## 말로 설명하기

LLM Wiki는 AI가 자료를 요약하는 데 더해 기존 주제 문서와 연결하고 갱신하는 지식 관리 방식입니다. Obsidian은 이를 읽고 편집하는 도구로 사용할 수 있고 RAG 검색과도 결합할 수 있습니다. 정리된 지식을 다시 읽어 활용하는 것이므로 모델 자체를 학습시키는 것과는 다릅니다. 원본과 정리본을 구분하고 출처와 변경 이력을 관리하는 것이 중요합니다.
